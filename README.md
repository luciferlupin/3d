# Icing on the Neck - Luxury Jewelry Store

An interactive 3D luxury jewelry store built with Three.js featuring realistic lighting, display cases, and premium jewelry items. "Icing on the Neck" specializes in fine necklaces and elegant jewelry pieces.

## Features

- **3D Environment**: Complete store interior with walls, floor, and ceiling
- **Display Cases**: Glass display cases with LED lighting
- **Jewelry Items**: 
  - Gold rings with diamonds
  - Silver necklaces with pendants
  - Bracelets with colorful gems
- **Interactive Controls**:
  - Mouse rotation for viewing
  - Scroll zoom
  - Auto-rotation toggle
  - Lighting toggle
  - Camera reset
- **Realistic Materials**: Metallic and gemstone materials with proper reflections

## How to Run

1. Open `index.html` in a modern web browser
2. The 3D store will load automatically
3. Use mouse to navigate around the store

## Controls

- **Mouse**: Click and drag to rotate the view
- **Scroll**: Zoom in/out
- **Reset View**: Return to default camera position
- **Toggle Lighting**: Turn accent lights on/off
- **Auto Rotate**: Start/stop automatic jewelry rotation

## Technical Details

- Built with Three.js r128
- WebGL rendering with shadows
- Physically based materials
- OrbitControls for navigation
- Responsive design

## Browser Requirements

- Modern browser with WebGL support
- Recommended: Chrome, Firefox, Safari, or Edge
